# CDet occupancy and projected response

`Plot_CDet_OccupancyResponse.C` contains the occupancy and expected-hit
diagnostics extracted from `Plot_CDet_PulsePixelTiming.C` on 2026-10-19.
It reads replay files directly in its main event loop. It does not require a
loader or a previous timing-macro call.

The timing macro now produces 13 timing, dt-versus-dx and LE/ToT canvases.
It no longer reads the geometry DB or creates occupancy/projection plots.
Its existing call signatures, cuts, fits and timing output directory are retained.

## Calling the macros

From `gocdetscripts`, with `OUT_DIR` set, start a fresh ROOT session after
updating the files:

```cpp
.L Plot_CDet_PulsePixelTiming.C+
Plot_CDet_PulsePixelTiming(6077, 19, nullptr, 1000);

.L Plot_CDet_OccupancyResponse.C+
Plot_CDet_OccupancyResponse(6077, 19, nullptr, 1000);
```

Either macro can run by itself; both can be loaded in the same session.
The numeric shorthand reads `CDet_run6077_occupancy_response.conf` for the new
macro. The configs are independent: editing one does not update the other.
The examples override the configured event limit to process 1,000 entries.
Omitting that argument uses `analysis.events`; `-1` reads all selected entries.

```cpp
// Explicit config, tag, study bar, input directory and entry limit:
Plot_CDet_OccupancyResponse("CDet_run6077_occupancy_response.conf",
                          "bar19_check", 19, "/path/to/Rootfiles", 1000);

// Optional ECal x display bin width/min/max, in metres, followed by output tag:
Plot_CDet_OccupancyResponse("CDet_run6077_occupancy_response.conf", 19,
                          nullptr, 1000, 0.0425, -1.5, 1.5, "bar19_check");
```

Bar IDs are global and zero-based; bar 19 contains pixels 304–319.
`occupancy_response.control_bar` chooses the control bar. Output tags use
letters, digits, underscores and hyphens; an empty tag defaults to
`run<run>_bar<study>_control<control>`.

## Outputs and selections

The new macro saves four PDFs and `projection_response_run<run>.csv` under
`OccupancyResponse/<tag>/`:

- Event occupancy, with both layers and study/control-bar zooms.
- ECal projection opportunities and observed CDet response counts.
- Conditional complete-pulse and final-selected response fractions.
- ECal x for the independent reference and for events with a selected pulse.

Occupancy counts each event at most once per pixel. Raw occupancy accepts any
stored complete pulse with a valid pixel ID. ECal occupancy additionally uses
the energy window, stored `ecal_eligible` flag and finite x residual. X-matched
occupancy additionally requires the configured absolute x residual window.
These occupancy curves do not impose LE/ToT, calibration-validity, spatial-pass
or ellipse cuts. `occupancy_response.occupancy_use_ecal_baseline` selects which
baseline curve is displayed; all three histograms remain available.

The opportunity denominator requires strict ECal energy/time windows, a
positive finite cluster count and finite ECal x/y. It requires no CDet pulse.
The configured DB timestamp supplies instrumented pixel positions, alignment,
residual offsets and default matching windows. Target-origin rays are compared
with every instrumented pixel, including pixels with no recorded pulse.

Blue filled fraction points count opportunities with any complete pulse.
Red open points require a pulse passing `good_final`: strict ECal energy,
finite timing/x-residual values, positive ToT, stored calibration/ECal/spatial
flags, inclusive LE bounds and the optional ToT window/ellipse. Each numerator
counts once per event/pixel. Both divide by the same opportunity count; error
bars are 68.3% binomial intervals. No opportunities means no point. Gray shading
marks unused slots. Broad matching windows can admit multiple pixels, so these
fractions are not intrinsic detection efficiencies.

`hECalX` still counts events with a final-selected pulse independently of the
reference selection. Changing reference timing or DB geometry does not rewrite
stored replay flags or pulse residuals. No calibration is reapplied.

Histogram and graph names are retained at the ROOT prompt, including
`hPixelOccupancyRaw`, `hProjectionOpportunities`, `hProjectionComplete`,
`hProjectionSelected`, `gProjectionCompleteFraction` and
`gProjectionSelectedFraction`. Reusing a tag overwrites matching outputs.
Old occupancy PDFs in `PulsePixelTiming/<tag>/` are historical files and are
not removed or regenerated by the timing macro.

## Validation

Compared both split macros against the pre-split source with ROOT 6.40 on the
first 1,000 Run 6077 events and a ten-event synthetic sample spanning a rollover
file. All 114 histograms with the ellipse disabled and 117 with it enabled
matched in entries, bin contents/errors (including flow bins), and axis edges.
Both fraction graphs matched in points and confidence intervals. The second
selection also enabled the ToT window, changed LE/energy cuts and selected raw
occupancy as the displayed baseline. Zero-pulse reference events and duplicate
pulses per pixel were checked explicitly. The timing-only config has no
projection DB or reference-time keys. The split produced 13 timing canvases
and four response canvases in one ROOT session. No full-run validation was done.

The comparison snapshot, driver and logs are local scratch artifacts under
`/private/tmp/cdet_occupancy_split`.
